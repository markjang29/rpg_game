## 핵심 원칙 (확정 · 타협 불가)

### 1. 걷기 보상 확정
보편적 걷기 목표 달성 시 게임 내 기회를 손해보지 않는다

### 2. P2W / T2W 차단
돈·시간이 '승패 우위'로 누적되지 않는다

### 3. 걷기 → 전투력 0기여 (★ 핵심)
걷기량이 전투 스탯·승률에 직결되지 않는다. 없으면 "오래 걷는 자 = 강해짐" T2W가 재발한다.

---

### 3겹 캡 — T2W 차단

| 캡 | 내용 |
|---|---|
| ① 입장권 로그캡 | 일일 보편 걷기 달성 시 전량 지급, 초과는 미적 보상(코스튬/기록) |
| ② 하루 N판 상한 | 전술 매치 일일 횟수 제한 |
| ③ 걷기→전투력 0기여 | 걷기량이 스탯/승률에 직결 ❌ |

---

### 코어 루프

```
걷기(일 6~8k보) → 입장재화(캡) → [동기화 전술 PvP / 지역 PvE / 캐릭터 성장·표현]
```

### Walk-to-Play 정당성
걸어서 모은 **원기옥**(세계를 붕괴에서 지탱하는 에너지 파편)이 전투·협동의 입장재화가 됩니다. 오염된 원기옥 파편이 혼종 몬스터를 만들어내기도 합니다.

### 색 염색 시스템 (마비노기풍)
- 걷기 → 색 팔레트 → 의상/코스튬 색 커스터마이징
- **표현층** (전투력 0기여 · 사진 원본 미저장)
- 정체성(전술 SRPG) 유지

### 소셜 & 진영
- **같이 걷기 → 입장권 2배**: BLE 근접 + 보행주기 동기화 + 경로 유사도 3중 검증
- **진영 분기**: 성별 고정 ❌, 내러티브 분기(길 잇는 자 vs 길 끊는 자)
- **로맨스**: 캐릭터 간 내러티브 로맨스 (파트너 캐릭터와 유대·서약)
