## 핵심 원칙 (확정 · 타협 불가)

### 1. 걷기 보상 확정
보편적 걷기 목표 달성 시 게임 내 기회를 손해보지 않는다

### 2. P2W/T2W 차단
돈·시간이 '승패 우위'로 누적되지 않는다

---

### 코어 루프

```
걷기(일 6~8k보) → 입장재화(캡) → [동기화 전술 PvP / 지역 PvE / 캐릭터 성장·표현]
                                       ↑ 공정한 경기           ↑ 협동·기록 경쟁
```

### 3겹 캡 — T2W 차단 (핵심)

1. **입장권 로그캡**: 일일 보편 걷기 달성 시 전량 지급, 초과는 미적 보상(코스튬/기록)
2. **하루 N판 상한**: 전술 매치 일일 횟수 제한
3. **걷기→전투력 0기여**: 걷기량이 전투 스탯/승률에 직결되지 않음

### 색 염색 시스템 (마비노기풍)

- 걷기→색 팔레트→의상/코스튬 색 커스터마이징
- **표현층** (전투력 0기여, 사진 원본 미저장)
- 정체성(전술 SRPG) 유지

### 소셜 & 진영

- **같이 걷기 → 입장권 2배**: BLE 근정 + 보행주기 동기화 + 경로 유사도 3중 검증
- **진영 분기**: 성별 고정 ❌, 내러티브 분기(길 잇는 자 vs 길 끊는 자)
- **로맨스**: 캐릭터 간 내러티브 로맨스(파트너 캐릭터와 유대·서약)
