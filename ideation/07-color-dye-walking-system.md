# 후속 수렴 — 걷기 기반 색 염색 시스템(마비노기풍) + 보강 방향

## 1. ✅ 확정 — 걷기 기반 색 염색 시스템 (마비노기풍 표현층)

**시그니처:** *"걸어서 모은 색으로 옷을 염색한다 — 걷기가 정체성의 언어가 된다."*

### 작동
- 걷기 + 특정 색 사진 채집 → **색 팔레트 누적**
- 색 팔레트로 **의상·코스튬·배경·UI 테마 색 커스터마이징** (마비노기 염색 참조)
- **표현층(정체성·소셜·코스튬) 전담. 전투력 0 기여.**

### 안전 (핵심 — 원본 미저장)
- 사진 **원본은 저장하지 않고 색 데이터만 추출/보관**. 안전 비용 영(0).
- "사진 구경/공유 피드"는 **불가 판정** — 유저×유저 로맨스 불가(`06 §7`)와 동일한 안전 자멸 조건 (배경 식별 역추적·미성년·UGC 모더레이션 비용).

### 진영 결정
- 색 **단독 판정 아님** → "걸음수 + 색(소프트 신호) + 시드" 혼합.
- 색 하드인증은 조작 우회(모니터 재촬영·AI 생성 5분)가 가능하므로 **소프트 신호로만** 사용.

### 내러티브 정합
- α "잃어버린 길"과 매핑: 빛/길 회복 = 난색(따뜻) 진영, 끊어진 발자국 = 잿빛/청색 진영.
- **색×이념 이원화(제안)**: 색은 진영의 *표현 층*, "길 잇/끊음"은 *내러티브 이념 층*. 같은 진영 안에서도 색이 다를 수 있어 갈등의 무게 유지.

---

## 2. 🟡 후보 — Walker's Chronicle (영구 성장 축)

이사님 "걷기에 영구 성장 동기를" 직관의 수렴안. 스태미나 총량 영구 증가(❌ 폐기)를 대체.

- 걷기 누적 → 캐릭터 로맨스 서사·코스튬·진영 서사 **영구 해금** (단일 '연대기' 진행축)
- 전술 매치 판 수·승률·전투력 **0 기여**
- 잉여 걷기의 공식 흡수구(캡① 설계와 정렬)
- **색 염색 시스템도 이 축의 일부** — 색 팔레트 = 연대기 수집 요소
- **상태:** 방향 제안, 후속 결정 대기

---

## 3. 🟡 후보 — PvP/PvE 분리 + PvE 보너스 참석

이사님 "전투력 직결 말고 던전 추가 참석은?" 직감의 수렴안.

- **PvP(대전)**: 캡②(하루 N판) 절대 엄수. 걷기 0 기여. 공평한 전술 결투장.
- **PvE(던전/레이드)**: 걷기로 **"보너스 참석" 허용**(상한 있게). 비경쟁이므로 T2W 독성 낮음.
- **안전장치**: (a) 상한 = 보편적 걷기로 도달 가능(이사님 3차 원칙 "기회 균등의 캡" 정합). (b) **PvE 보상 ↔ PvP 전투력 단절** — PvE 수집품이 PvP 승패로 역류 금지. PvE 보상은 Walker's Chronicle(코스튬/내러티브) 축으로만.
- **상태:** 방향 제안, 후속 결정 대기

---

## 4. ❌ 폐기 (이번 세션)

| 폐기안 | 사유 |
|---|---|
| 걷기 → 스태미나 총량 영구 증가 | 캡②(하루 N판) 해체 → T2W 재발 ("스태미나 총량 = 하루 N판 = 캡②" 등식) |
| 스태미나를 "전투 내 자원(집중/행동력)"으로 우회 | 캡③(걷기→전투력 0기여) 위반의 역류 경로 |
| 베이스를 색사진 수집으로 전복 ("전투=양념") | ① 안전: 사진 공유 피드 자멸 ② 정체성: §1.6 전술 SRPG 근거 붕괴 ③ 리텐션: 6개월 팔레트 포화 |
| "사진 구경/공유" USP | 원본 보존=안전 폭발, 원본 미저장=USP 소멸 → 모순 |
| 대전(PvP) 완전 삭除 | 전술 SRPG 정체성 상실 + PvE-only 수익 약함(인디 85% 재정 실패) |

---

## 5. 확정 원칙 재확인 (1안 유지)

- **정체성: 전술 SRPG 메인 유지** — 색 염색은 표현층 가미, 정체성 전복 아님.
- **3겹 캡 유지**: ① 입장권 로그캡 ② 하루 N판 ③ 걷기→전투력 0기여
- **전투는 양념이 아니라 코어** — "갈등의 결산 무대"이자 두 번째 리텐션 기둥.

---

## 6. 🟡 후보 — 추가 안전장치

- **캡 ④(제안)**: 진영 보상은 표현(코스튬/타이틀) 전용. 색 수집량이 진영 전력으로 환산되지 않게 — 안 하면 T2W 우회로(소수 진영 보너스 등) 발생.
- **색×이념 이원화(제안)**: §1 참조.

---

## 7. 🟡 제안 — 개발 방향 (모듈식, 엔진 무관 우선)

"작은 것부터, 구획 잘게, 개별 평가 + 재사용, 변경 즉시 테스트"(이사님).

- **원칙**: 퓨어 로직(엔진/렌더링 무관) vs 표현(씬) 분리. "로직은 게임에 적용, 테스트는 변경 즉시."
- **MVP 순서(제안)**: M1 패링/타이밍(의존성 0, 엔진 무관, 즉시 체감) → M5 캡 경제 + M7 성장 → M3 보드 + M2 전투 → M4 턴(PvE) → M6 걷기 → M11 매칭.
- **색 염색 모듈**: 순수 로직(색 팔레트 상태·염색 규칙) + 표현(씬 렌더링). M1과 같은 패턴으로 독립 테스트 가능.
- **엔진 ADR**: Godot(권장) 조기 확정 권고 — M3(보드)부터 엔진 투자 본격화.
