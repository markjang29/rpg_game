# 걷기 기반 예측 버퍼

`prediction_buffer`는 내부 식별자다. 사용자에게 보일 이름은 **예측 버퍼 / 인지 여유 / 동기화 에너지** 중 어느 것도 아직 확정하지 않는다.

## 정체성

걷기는 공격력이나 정답을 사는 수단이 아니라 **실수할 수 있는 시간과 한 번 더 생각할 기회**를 준비하는 행동이다.

## 사용 후보

- 패링·회피 허용 구간을 소폭 확장한다.
- AI에게 독립적인 두 번째 예측이나 반대 가설 분석을 요청한다.
- 짧은 순간 체감 시간을 느리게 해 관찰 정보를 더 읽는다.
- 제한된 조건에서 치명적인 오판 한 번을 취소한다.
- 충돌하는 두 예측 중 하나의 근거를 더 자세히 푼다.

기존 대화의 `0.1~0.3초`는 프로토타입 탐색 범위일 뿐 확정 수치가 아니다.

## 자원 획득 원칙

| 경로 | 역할 |
|---|---|
| 게임 내 기본 회복 | 걷지 않은 날도 핵심 게임을 플레이 가능하게 한다 |
| 현실 걷기 | 일일 상한이 있는 의미 있는 보너스 |
| 게임 내 훈련/플레이 기록 | 걷기 어려운 사용자의 대체 획득 경로 |
| 접근성 활동 | 보행 능력과 무관한 동등한 참여 경로 |

## 금지

- 걷지 않으면 스토리를 진행할 수 없는 하드 게이트.
- 무제한 누적으로 보스를 압도하는 구조.
- 걷기량이 AI의 지능·정답률·캐릭터 공격력을 직접 올리는 구조.
- PvP에서 보행량이 승패를 사실상 결정하는 구조.
- 건강 데이터 원문을 불필요하게 Git이나 콘텐츠 자산에 저장하는 것.

## AI 성장과의 분리

- **AI 성장**: 실제 관찰, 성공·실패, 세계 규칙 발견으로 예측 모델과 설명이 정교해진다.
- **걷기 버퍼**: 이미 나온 예측을 검토하거나 반응할 시간과 추가 질의 기회를 준다.

둘을 분리해야 “많이 걸으면 AI가 정답을 알려준다”는 자동 승리 구조를 막을 수 있다.

## 검증 질문

- 보너스가 없어도 전투가 공정하고 즐거운가?
- 보너스가 있으면 강해졌다기보다 여유가 생겼다고 느끼는가?
- 걷기와 대체 활동의 시간 대비 효용이 납득 가능한가?
- 오판 취소가 긴장을 없애지 않고 전략 자원으로 남는가?
