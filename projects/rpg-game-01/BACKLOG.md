# 결정·검증 백로그

## 지금 함께 디벨롭할 것

1. **P0 — 핵심 음모**

   강제 이동 주체, 원본 현실, 공장 목적, AI의 비밀, 마지막 선택을 정한다.

2. **P0 — 게임명**

   음모 승인 후 핵심 상징·동사·감정에서 후보를 만들고 결정한다.

3. **P1 — 첫 세계의 역할**

   구체 세계를 먼저 지어내지 말고, 첫 세계가 어떤 규칙을 가르치고 어떤 장기 단서를 남겨야 하는지 기능부터 정한다.

4. **P1 — 주인공과 AI 관계 곡선**

   신뢰→의심→공모/대립 가능성을 장별로 배치한다. 구체 인스턴스는 이사님 체감 게이트 후 만든다.

## 그 다음 검증할 것

- 관찰형 패링의 60~90초짜리 독립 프로토타입.
- 눈 UI가 QTE가 아닌 추론 도구로 읽히는지 사용자 테스트.
- 걷기 버퍼 없이도 공정하고, 있을 때 “강함”보다 “여유”로 느껴지는지 테스트.
- 한 세계의 문화 규칙을 알아낸 것이 전투 판단을 바꾸는 세로 조각.
- 같은 캐릭터의 두 버전에서 무엇을 합치고 버릴지 선택하는 서사 조각.
- 매트릭스의 검토된 JSON 조각을 RPG 세계 로드 입력으로 바꾸는 어댑터 계약.

## 구현 전 게이트

- [ ] 핵심 음모 승인.
- [ ] 첫 세로 조각의 감정 목표 승인.
- [ ] 사용할 세계·캐릭터·페르소나 인스턴스 체감/승인.
- [ ] 관찰 전투 성공 기준 합의.
- [ ] 걷기·접근성·PvP 공정성 원칙 검수.
- [ ] 매트릭스 입력의 출처·재현성·예산 검증.

## 지금 하지 않는 것

- 제목부터 확정하기.
- 첫 세계·주인공·AI 이름을 임의 생성하기.
- AWS 배포나 본편 통합 구현.
- 폐기된 제조공장 은폐 시나리오 재사용.
