# [WIP/draft] Reasoning-Parry 두 번째 전투 씬 설계 프레임워크

> **야간 배정(2026-07-04 01:00 KST)** 산출물. 튜토리얼(`reasoning` 모듈) 다음 단계의 전투 씬 설계.
> 첫 씬은 단일 플레이어 vs 단일 적, 1 턴 1 패링. 두 번째 씬은 **난이도 확장** — 보스전 또는 다중 패링 연계.
> 본 문서는 설계 프레임워크(draft). 전략 채택/ADR/commit은 아침 승인 후.

---

## 1. 목표 — "시그니처 루프의 난이도 확장"

첫 씬(`reasoning`)이 가르친 것:
- 참모 추론(작전안 3 + 위험%) / 지휘관 결정(전제 토글·선택) / 패링(±70ms).

두 번째 씬이 **새로 가르칠 것** (한 가지에 집중 — persona §3):
- **보스전의 핵심 단위**: 패턴 변화 / 다중 패링 / 편향 정정의 실전 체감.

---

## 2. 세 가지 방향 (후보 — 채택은 아침)

### 방향 A — "속이는 자" (패턴 변화 + 페인트) ★ 추천
> 적이 **패턴을 바꾸고 속인다**. 참모의 편향 정정이 빛나는 한 장면.

- 적: 그림자 자객. HP 3.
- 턴이 진행될수록 적 패턴 변화 (속도↑, 페인트 추가).
- 참모가 "속도 변화 감지" → 플레이어가 심층 분석으로 편향 정정 체감.

### 방향 B — "연격" (다중 패링 연계)
> 적이 **3연속 시차 투사체**를 쏜다. 3연속 패링 쾌감.

- 적: 쌍둥이 궁수. 한 번에 3발 시차 공격.
- 참모: "3연속. 간격 0.4초. 첫 번째는 미끼일 수 있음."
- 플레이어: 3연속 패링 (Perfect/Good/Miss 판정 각각).

### 방향 C — "작은 보스" (HP 게이지 + 단계별 패턴)
> 적 HP 3, **단계별 패턴**. `ideation 10` 보스전의 축소판.

- 적: 오크 전사. HP 3.
- HP 2 → 속도↑. HP 1 → 광역(2개 투사체).
- `ideation 10` 4인 파티 보스전으로 가는 자연스러운 징검다리.

---

## 3. ★ 추천 설계 — 방향 A + C 혼합 ("그림자 자객, 3단계")

> 방향 A(패턴 변화/페인트)와 C(HP 게이지/단계)를 합친 한 장면.
> `ideation 10` 보스전으로 넘어가기 가장 자연스러운 "작은 보스" 형태.

### 3.1 씬 개요

- **적**: 그림자 자객 (HP 3, 패턴 변화형)
- **플레이어**: 단일 (첫 씬과 동일 — 4인 파티는 `party_boss` 모듈에서)
- **참모**: 공격형 편향 유지(`reasoning` 모듈과 동일), 심층 분석 시 정정

### 3.2 3단계 패턴 (show, do not tell)

**[턴 1 — 기본]** (HP 3 → 2)
```
참모 칩: "적 HP 3. 단일 공격 위험 32%."
참모(편향): "맞받아치기(B) 추천." (공격형 — 위험 0.66배 과소평가, 실제 38%)

[플레이어: 심층 분석(토큰 1)]
  → "정정: 보정 전 위험 38%."

[플레이어: 방어 작전안 선택]
  → 적 이동 → telegraph(0.55초) → 투사체
  → 패링(Perfect) → 적 HP 2.

참모: "좋습니다. 하지만 얘, 패턴을 바꿀 겁니다."
```

**[턴 2 — 패턴 변화 + 페인트]** (HP 2 → 1)
```
적: 속도 1.3배. 깜빡임 2번( telegraph 변형).
  첫 번째 깜빡 → 투사체 (미끼 — 느림)
  두 번째 깜빡 → 진짜 투사체 (빠름)

참모 칩: "속도 변화 감지. 70% 확신 — 2번째 깜빡 후 공격."

[플레이어: 2번째 깜빡에 패링 → Miss (미끼였음)]
참모 칩: "정정: 첫 번째가 미끼였습니다. 진짜는 지금!"
  → [진짜 투사체 도착 → 패링(Good)] → 적 HP 1.

참모: "...제가 속았습니다. 주의하세요, 얘는 교활합니다."
```

**[턴 3 — 분노 광역]** (HP 1 → 0)
```
적: 분노. 3개 투사체 동시(시차 0.4초).

참모 칩: "광역! 3연속 패링 필요. 간격 0.4초."

[플레이어: 3연속 패링]
  1번: Perfect
  2번: Good
  3번: Perfect
  → 적 처치.

참모: "위험했지만, 잘 막으셨습니다. ...이런 녀석이 보스전에 나옵니다."
```

### 3.3 show, do not tell 핵심

플레이어가 **직접 체감**하는 것:
1. **참모 편향** — "맞받으래? 근데 위험 표시가 낮다. 이상한데?" → 심층 분석으로 정정.
2. **패턴 변화** — "어? 속도가 빨라졌네." → 참모 경고.
3. **페인트 속임** — "2번째에 패링했는데 Miss? 미끼였어?" → 참모 정정.
4. **광역 연격** — "3연속? 간격 0.4초?" → 손맛 폭발.

→ "AI가 정답을 알려주는 게임"이 아니라 **"편향 있는 참모와 심리전하는 게임"**을 체감.

## 4. 난이도 곡선 (튜닝값 — 본편 조립 시점)

| 턴 | 적 HP | 패턴 | 참모 확신도 | 패링 난이도 |
|---|---|---|---|---|
| 1 | 3→2 | 단일, telegraph 0.55초 | 70% (편향) | 쉬움 (±155ms Good) |
| 2 | 2→1 | 속도↑, 페인트 | 70% (정정 필요) | 중 (±70ms Perfect 어려움) |
| 3 | 1→0 | 광역 3연격 | 85% | 어려움 (3회 연속) |

## 5. `reasoning` 모듈과의 관계

### 재사용
- 상태 머신: ADVISOR → ENEMY_TURN → RESOLVE → GAMEOVER (`reasoning.gd` 동일)
- 패링 판정: PERFECT_WINDOW(±70ms) / GOOD_WINDOW(±155ms) (`shared/` 재사용)
- 위험 모델: 거리 기반 + 편향 계수(0.66)
- 참모 칩 UI: 한 줄 결론 + 근거 칩 ≤3

### 확장 (새로 추가)
- **적 HP 게이지** (3단) — `reasoning`은 적 HP 1이었음.
- **패턴 변화** — 적 speed/telegraph 가변 (`reasoning`은 고정).
- **페인트 투사체** — 미끼 투사체(판정 무효) + 진짜 투사체.
- **광역(다중 투사체)** — `reasoning`은 단일 투사체.

→ `reasoning` 모듈을 복사 → `shadow_assassin` 모듈로 확장. shared/ FX/SFX 그대로.
