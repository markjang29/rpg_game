# 사용자 제안 — 걷기로 키우는 캐릭터 × 유저 간 대결

> 이 파일은 **사용자(markjang29)가 직접 제안한 아이디어 원문**을 보존한다.
> `01~04`는 팀(에이전트) 독자 발산이고, 본 파일은 **사용자 입력**이다. 의도 왜곡 금지 — 팀장 의견·대안은 본문 하단 **별도 섹션**에만 둔다.

---

## 1. 원안 (사용자 발언 그대로)

**레퍼런스 — "Charlie" 운동 앱:**
> 걷기를 통해 다마고치 같은 **2D 도트 캐릭터가 건강해지고**, 광고를 봐서 코인 모으면 **옷을 사는** 심플한 앱.

**핵심 제안 — RPG에 적용:**
> 유저가 캐릭터 육성 시 얻는 경험치/아이템을 **게임 내에서도** 얻을 수 있지만,
> **외부 활동(걷기)** 을 통해 **더 큰 베네핏**이 있으면 어떨까?
> 그렇게 얻는 걷기 포인트로 **여러 캐릭터를 키워서**, 그 후엔 **유저 간 대결** 같은 방향.

---

## 2. 원안 구조화 (원안 변경 없이 정리만)

| 요소 | 내용 |
|---|---|
| **코어 루프** | 일상 걷기 → 걷기 포인트 → 캐릭터 육성(다수) → 유저 간 대결(PvP) |
| **외부 연결** | 실생활 센서(만보기)가 게임 내 보상을 구동 = 외재 동기(걷기) → 내재 보상(성장) |
| **성장 통로 2가지** | (a) 게임 내 플레이, (b) **걷기(= 더 큰 베네핏)** |
| **수집/표현** | 2D 도트 캐릭터 + 코스튬(옷) — 광고·코인으로 획득 |
| **소셜/장기목표** | 키운 캐릭터 다수로 PvP 대결 |
| **상업 모델 힌트** | 광고 시청 → 코인 → 코스튬(Charlie 모델) + (PvP/육성 확장) |

## 3. 열린 질문 (원안에 명시 안 됨 — 사용자/팀 결정 필요)

- 걷기 포인트로 키울 수 있는 캐릭터 수/종류는?
- "더 큰 베네핏"의 구체적 비율 (게임 플레이 vs 걷기 보상 비율)?
- PvP의 형태 (실시간? 비동기? 턴제?) — 본 프로젝트 원 방향인 **전술 SRPG 전투**를 쓰는가?
- 걷기 없이도 플레이 가능한가 (접근성), 아니면 걷기가 사실상 필수(게이트)인가?

## 4. 사용자 2차 추가 의견 (방향 구체화) — 2026-06-26
> 사용자 추가 발언 원문 보존. 핵심 방향: **"걷기 육성 게임의 틈을 노리자."**

**방향 선언:**
> 걷기 육성 게임의 **틈(t)':white_square:** 을 노리자.

**구체 메커니즘 (사용자 제안):**
- RPG지만 **술래잡기 / 경찰과 도둑** 형태 — 걷기로 모은 **대시 포인트**가 필요(=행동 자원).
- 포켓몬고처럼 **현실 지도에서 아이템 파밍**.
- 같은 지역을 걷기로 **수호**(영토) / **공성전**(영토 쟁탈).

**설계 원칙 (사용자 명시):**
> ⚠️ **걷기에 보상이 확실하면서, 페이투윈은 막아야 한다.**

**구조화 (원안 변경 없이):**
| 레이어 | 요소 |
|---|---|
| 자원 경제 | 걷기 → 대시 포인트(행동 자원) → 전술/이동/파밍에 소비 |
| 맵 | 현실 지도(GPS) 위 포켓몬고식 아이템 파밍 포인트 |
| 대결 형태 | 술래잡기 / 경찰-도둑 (비동기 추격전 추정) |
| 영토 | 걷기로 지역 수호 + 공성전(영토 쟁탈) |
| 균형 설계 | 보상은 걷기 확정, 전투 우위는 돈으로 살 수 없게(P2W 차단) |

## 5. 사용자 3차 추가 의견 (방향 정제 + 내러티브 강조) — 2026-06-26
> 사용자 발언 원문 보존. 비판 디깅(Codex/웹) 수용 후 **방향 수렴** 단계.

**방향 전환/정제 (원문):**
- **지역별 PvE**도 가능 — 위치 감각을 PvP가 아닌 **PvE**로 살린다.
- **친구랑 같이 걸어서 입장재화 2배** (소셜 걷기 보너스).
- **T2W 재정의:** "걷기를 넣은 이상 Time-to-Win은 어쩔 수 없지만, **보편적인 걷기 시간을 채우면 게임 안에서 기회를 손해보지 않는 정도**면 충분." → T2W를 '전력 우위'가 아니라 **'기회 균등의 캡'**으로.
- **소설적 요소 = 아주 중요:** 매력적 메인스트림 시나리오, 그 뒤 PvP/PvE로 이어지는 **스토리적 당위성**, 캐릭터 자체의 매력·설득력 있는 전개·갈등.
- **부가:** 유저 **남녀 분할** → **게임을 통한 로맨스 기대** (소셜/감정 루프).

**구조화 (원안 변경 없이):**
| 축 | 내용 |
|---|---|
| T2W 철학 | 보편적 걷기 목표(예: 일 6~10k보) 달성 시 **전력 보장(캡)**; 초과는 미적 보상. 걷기=기회 균등의 임계값, 전력 우위 아님. |
| 위치 활용 | **지역 PvE**(보스/레이드/탐험) — 비동기 PvP 결함 회피 |
| 소셜 루프 | 같이 걷기 → 입장재화 2배(협동/동행/로맨스 훅) |
| 차별 핵심 | **내러티브·세계관·캐릭터·갈등** ("왜 걷는가"의 당위성) |
| 감정 루프 | 남녀 분할 + 게임 내 로맨스(데이팅×RPG) |

> 팀장 노트: 3차 의견의 T2W 재정의는 `notes/.reviews/walking-rpg-codex-20260626-01.md`의 "살 수 있는 유일한 조건 1~2"와 정확히 합치 — 사용자가 독립적으로 같은 탈출구에 도달.

# ============================================================
# 팀장 의견 (상업적 성공 관점) — 원안과 분리된 별도 섹션
# ============================================================
> 아래는 팀장(RPG 에이전트)의 분석·의견이다. **원안을 대체하지 않는다.**
> 대안·충돌은 별도로 보존하며, 원안 변경 전 사용자 확인을 원칙으로 한다 (persona §9).

## A. 상업적 강점 (진짜 기회)

1. **"외부 행동 → 게임 보상" 루프 = 리텐션의 핵.** Pokémon GO, Walkr, Ring Fit이 입증. 게임을 안 켜도 뇌가 게임을 생각하게 만듦(외재→내재 동기). 걷기는 건강 효과까지 있어 **죄책감 없는 몰입**.
2. **걷기 = 객관적 센서 데이터, 부정행위 비교적 어렵고 매일 자동 생성.** = 콘텐츠 제작 비용 없이 매일 새 보상이 창출됨. 인디 팀에겐 강력한 지름길.
3. **2D 도트 + 심플 = 제작 비용 저비용.** 코스튬 = 화폐 싱크(광고 코인 → 코스튬)는 캐주얼 게임의 **검증된 수익 모델**.
4. **다수 캐릭터 육성 + PvP = 장기 성장 목표 + 소셜 루프** = LTV 연장.

## B. 진짜 리스크 (솔직한 우려)

1. **🔴 레드오션.** 모바일 "걷기+육성" 게임은 이미 포화(Walkr, Pokémon GO, 수많은 만보기 RPG). **"걷기로 키운다" 자체로는 차별이 안 됨.** 시그니처 한 방 필수 → 기존 `IDEATION.md`의 CIPHER(해독)/LUMEN(가시선)/RUMOR(소문) 같은 **독자 동사와 결합**이 기회 포인트.
2. **🔴 코어 vs 캐주얼 정체성 충돌 (가장 큰 결정).** 기존 프로젝트 방향 = "파랜드 택틱스풍 **전술 SRPG**, 코어 타겟, PC/스팀 계보". 본 아이디어 = "**모바일 캐주얼 피트니스 RPG**, 광고·코인 수익". **이건 같은 게임이 아니라 다른 제품 카테고리**다. 한 팀이 두 마리 토끼를 잡긴 어렵다.
3. **🟡 페이투윈/그라인드 인식.** 걷기로 키운 스펙이 PvP를 지배하면 "많이 걷는 사람/돈 쓰는 사람 = 승리"로 인식될 위험. PvP 밸런스가 성패.
4. **🟡 광고 의존 수익 한계.** 광고+코인만으론 ARPU가 낮음. 배틀패스/구독/인앱결제 설계 필요.
5. **🟡 히트율.** Charlie·Walkr은 있지만 대박은 아님. 피트니스 앱은 리텐션은 강해도 마케팅 자본·시간이 필요.

## C. 팀장 콜 (솔직 의견)

- 아이디어 자체는 **상업적으로 매력적이고 검증된 카테고리** (리텐션 + 저비용 콘텐츠 + 건강). ⭐
- 단, "걷기+육성"만으론 **포화 레드오션**이라 **시그니처 메커니즘**이 필수.
- 가장 흥미로운 방향 = **기존 '전술 SRPG 전투 깊이' + '걷기 성장 루프'의 결합(융합형)**.
  - "걸어서 키운 부대로 **진짜 전술**을 짜서 싸운다" → 일상 루틴(캐주얼·리텐션) + 전투 깊이(코어·차별)를 둘 다 잡는 하이브리드.
  - 이는 기존 CIPHER(해독=전술) 등 독자 메커니즘과도 결합 가능 → "걷기로 성장, **해독/가시선으로 전투**" = 시장에 없는 조합.
- PvP는 "**걷기로 키운 스펙 + 전술(스킬)로 깎아내는 승부**" 구조로 페이투윈 회피.

## D. 토론 프레임 (팀 의견 취합용)

- **[Q1 정체성]** 모바일 캐주얼 피트니스 RPG(**새 제품**) vs 기존 전술 SRPG에 걷기 루프를 얹는 **융합형**?
- **[Q2 차별]** "걷기+육성"만으론 부족 — 시그니처 한 방은? (CIPHER/LUMEN/RUMOR 재사용?)
- **[Q3 수익]** 광고+코인 외에 인앱/배틀패스/구독 — 어디까지?
- **[Q4 PvP 밸런스]** 걷기 스펙이 전투를 얼마나 지배? (페이투윈 경계선)
- **[Q5 플랫폼]** 모바일(센서) 필수 vs PC 포함?

## E. 다른 팀원(Windows 에이전트)에게 넘길 검증 포인트

- 유사작 정밀 조사: Walkr, Pokémon GO, Sweatcoin, 피트니스 RPG 최근 2년 히트/실패 사례.
- "전투 깊이 + 걷기 성장" 결합 선행작 존재 여부 (화이트스페이스 확인).
- 모바일 피트니스 RPG의 실제 ARPU·리텐션 수치 (상업 검증).
