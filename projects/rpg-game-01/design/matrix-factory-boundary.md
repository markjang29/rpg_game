# 매트릭스 공장과 RPG GAME 01의 경계

## 두 가지 역할

매트릭스는 동시에 두 층에서 작동한다.

1. **제작 도구** — 검토된 세계·캐릭터·페르소나·모듈·서사 청사진을 명시적 규칙으로 조립한다.
2. **게임 속 장치** — 주인공에게 세계와 임시 역할·관계를 로드하는 공장/시스템으로 표현된다.

이 둘을 맞추면 “콘텐츠 생성 파이프라인”이 게임 설정과 플레이 구조의 일부가 된다.

## RPG가 받을 최소 정보

향후 어댑터가 전달해야 할 개념적 묶음은 다음과 같다. 이는 인터페이스 방향이며 구현 완료를 뜻하지 않는다.

- 사용한 세계·캐릭터·페르소나·모듈·서사 청사진의 정확한 참조.
- 각 구성요소의 역할과 세계별 변형 범위.
- 명시적인 조합·융합·충돌 해결 규칙.
- 세계의 문화·서사·전투 문법.
- 주인공에게 부여되는 임시 역할과 관계의 출처.
- 장기 미스터리에 기여할 단서 슬롯.
- 재현 가능한 조합 식별자와 출처.
- 생성 예산과 누락·대체된 요소.

## 조립 원칙

- 검토된 구성요소만 사용한다.
- “랜덤하게 붙였다”로 끝내지 않고 왜 이 조합이 성립하는지 규칙을 둔다.
- 원형 자산과 세계 인스턴스, 플레이 중 상태를 분리한다.
- 캐릭터 원형과 세계별 버전을 분리한다.
- 능력·기억·관계 융합은 명시적 충돌 규칙과 출처를 가진다.
- 같은 입력과 규칙으로 조합을 다시 설명·검증할 수 있어야 한다.
- 구체 캐릭터·세계 인스턴스는 이사님 체감·승인 전에 제품 정본으로 승격하지 않는다.

## 자산 정책

- Git에는 구조화된 정본과 검증 가능한 참조를 둔다.
- 원본 이미지·대용량 바이너리를 RPG 프로젝트에 임의 복사하지 않는다.
- 이미지 에셋은 향후 NAI·SD Forge 등 재생성의 근거가 될 분류·설명·출처 연결을 우선한다.
- RPG는 매트릭스 자산의 정체성 핵을 임의 평균화하거나 복사 DTO로 변형하지 않는다.

## 아직 없는 것

- RPG GAME 01 전용 세계 로드 패킷의 확정 스키마.
- 실제 게임 런타임 어댑터.
- 승인된 주인공·AI 안내자·첫 세계 인스턴스.
- 플레이 이벤트를 매트릭스 연속성으로 되돌리는 리듀서.
- AWS 또는 로컬에서 실행되는 제품 E2E.

이 항목은 구현 단계에서 각각 별도 검증과 승인을 거친다.
