# 코어 빙의 (정체성 핵 → 세계 캐릭터)

> 이사님 2026-07-26 아이디어. 정본 `multiverse-continuity.md`의 **정체성 핵(identity kernel)** 을 게임 메커니즘으로 구체화. **세계 간 이동 형태는 tbd** — 이사님 결정 대기.

## 정의

플레이어 캐릭터의 **성장 본질 = 코어**(정체성 핵). 코어가 각 세계의 캐릭터에 **빙의**해 플레이. 세계가 바뀌면(빙의 대상 교체) 껍데기는 바뀌어도 **코어의 성장은 유지**.

## 정본과의 정합 (1:1 대응)

정본 `multiverse-continuity.md` 원문에 이미 정의됨:

- **코어** = "변하지 않는 **정체성 핵**(identity kernel)"
- **빙의 대상(세계 캐릭터)** = "해당 세계에서만 생긴 역할과 관계"(세계 인스턴스)
- **성장 유지** = "세계를 넘어 보존 가능한 경험"(추출 조각)

즉 이사님 아이디어는 정본 메타 정체성 층의 **게임적 구현**. 충돌 0.

## 왜 좋은가

1. **성장 영속** — 세계가 바뀌어도 코어 성장 유지 → 멀티버스에서 "내가 키운 것"이 안 사라짐 → **성장 동기**(이사님 포인트).
2. **서사 본질** — "코어가 왜 세계를 떠돌며 빙의하는가?" = 정본 `core-loop`의 **장기 미스터리**(붕괴 원인·단서 슬롯). 빙의가 서사 뼈대.
3. **정령무기 연결** — 정령무기를 코어가 장비/흡수. 또는 코어의 표현.
4. **장기말 카테고리 연결** — 코어가 빙의한 캐릭터 = 장기말 하나(`tactical-ai.md`의 이동 카테고리 보유).

## 세계 간 이동 (★ tbd — 이사님 결정 대기)

세계 **안**은 `scale-zoom.md`(슈프림 줌). **세계 간** 이동 형태는 후보:

- **(기본) 강제 로드/추출** — 정본 `core-loop`·`multiverse-continuity` 기준. 코어가 세계에 강제로 던져지고, 강제 추출→다음 세계. 서사 긴장.
- **(후보 A) 자유 이동** — 플레이어가 원할 때 다른 세계로. 자율성 ↑ but 강제성(긴장) ↓, 정본과 충돌 가능.
- **(후보 B) 시간선 넘나들기** — 시간축 이동(같은 세계의 과거/미래, 또는 시간 분기). `core-loop`의 "붕괴 원인·단서"가 시간 축에 흩어질 수 있음.
- **(후보 C) 하이브리드 해금** — 기본은 강제, 코어 성장·서사 단서로 **자유/시간선 해금**. 초기 강제 → 점진 자율.

## 미정 (details-tbd)

- 세계 간 이동 형태(위 4후보 중 이사님 결정).
- 빙의 대상 교체 시 조작감/정체감 보존 방식(코어+껍데기 분리).
- 인스턴스 정책 — 코어는 정체성 핵 아키타입(정본), **구체 빙의 대상**은 매트릭스 생성 + 이사님 체감 후(정본 원칙).
- 코어 성장의 구체 스탯/능력 분류.
- 서사 정합(빙의 메커니즘 서사) — 시나리오 팀 협업, 시나리오 잠금 고려.

## 왜 넣는가

코어 빙의는 멀티버스·정령무기·장기말·줌 스케일을 "주인공의 정체"로 묶는 중심 축. 정본 identity kernel의 게임화로, 기존 설계와 충돌 없이 성장 동기·서사 후킹을 강화한다.
