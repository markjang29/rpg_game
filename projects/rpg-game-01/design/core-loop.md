# 코어 루프

## 장기 루프

```text
현실 활동/게임 내 훈련
  → 예측 버퍼 준비
  → 세계 강제 로드
  → 임시 역할·관계 수신
  → 세계/서사/전투 문법 조사
  → 관찰·AI 예측·판단·패링
  → 붕괴 원인과 장기 미스터리 단서 발견
  → 기억·능력·관계 조각 획득 또는 상실
  → 강제 추출/완주
  → 본래 주인공과 AI의 지속 상태 갱신
  → 다음 세계
```

## 한 세계의 플레이 단계

| 단계 | 플레이어가 하는 일 | 세계가 제공하는 것 | 지속되는 것 |
|---|---|---|---|
| 로드 | 상황을 파악하고 임시 정체성을 받아들인다 | 역할·관계·위기·금기 | 로드 출처와 불일치 단서 |
| 조사 | 인물의 말과 사건의 규칙을 비교한다 | 문화·서사·거짓말·전투 문법 | 확인된 규칙과 의심 |
| 충돌 | 관찰하고 AI 예측을 평가해 행동한다 | 적의 텔·속임수·규칙 변화 | 플레이어/AI 학습 |
| 선택 | 세계를 구할지, 이용할지, 포기할지 결정한다 | 대가·관계 변화·붕괴 | 기억·능력·관계 조각 |
| 추출 | 완주 또는 강제 이동을 겪는다 | 미완의 약속·추격·단서 | 메타 미스터리와 후유증 |

## 재미의 세 층

1. **즉시 재미 — 읽고 반응하기**: 눈과 몸동작, AI의 불완전한 예측, 패링·회피의 손맛.
2. **에피소드 재미 — 세계를 이해하기**: “이 이야기의 규칙은 무엇인가”를 추리하고 인물과 관계 맺기.
3. **장기 재미 — 나를 조립하기**: 여러 세계의 기억·능력·상처·관계와 동일 인물의 다른 버전을 어떻게 합칠지 선택하기.

## 실패가 남기는 것

실패는 단순 재시작이 아니다. 어떤 오판을 했는지, AI가 무엇을 잘못 읽었는지, 어떤 관계를 끝내지 못했는지가 이후 세계에서 단서나 편향으로 돌아올 수 있다. 구체 저장·리듀서 규칙은 아직 구현하지 않으며, 런타임 설계 때 별도 승인한다.

## 아직 검증할 것

- 세계 조사와 전투의 비중.
- 한 세계 체류 시간과 강제 추출 빈도.
- 세계를 완주하지 못해도 납득되는 보상과 감정적 여운.
- 장르가 달라도 관찰·예측·선택이라는 공통 조작이 유지되는지.
