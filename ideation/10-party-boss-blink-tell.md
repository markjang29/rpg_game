# 4인 파티 보스전 — 걷기 심리전 × 눈 깜빡임 텔 × 패링

> 2026-07-03 이사님 세션에서 **4인 파티 보스전 구조 확정**. Walk-to-Play 원칙(걷기→윈도우)을 유지하며, 전투를 1:1 진검승부에서 **4인 파티 vs 보스**로 전환. 보스 눈 깜빡임을 텔로 사용하고, 패링 성공이 큰 어드벤티지.

---

## 상태 범례
- ✅ **확정** — 이사님 본 세션 채택
- 🟡 **후보/설계** — 방향 잡혔으나 프로토타입 검증에 위임
- ❌ **폐기** — 본 세션 기각

---

## 1. ✅ 확정 — 한 줄 정의

> 캐릭터 4인 파티가 보스를 상대로, **걷기로 벌어진 윈도우 차이**를 심리전으로 삼고, **보스 눈 깜빡임 텔**을 읽어 패링 타이밍을 잡으며, 광역기는 파티 전체가 동시에 회피/패링하는 턴제 보스전.

---

## 2. ✅ 확정 — Walk-to-Play 원칙 유지

- 걷기 = **시간 심리전**(언제 공격/회피할지?). 윈도우 5.0초 → 7000보=5.7초.
- 자원 소비처 분기(룩 or 윈도우), 캡, PvE/PvP 분리 — **`09` 그대로 유지**.
- 전투 구조만 1:1 → **4인 파티 보스전**으로 변경.

---

## 3. ✅ 확정 — 4인 파티 구성

전형적인 RPG 역할 분담 (예시 — 확정 아님, 조정 가능):

| 역할 | 특성 | 윈도우 예시 |
|---|---|---|
| **탱커** | 보스 어그로 끌기, 높은 방어 | 5.7초 (걷기 많이 한 캐릭터) |
| **근접 딜러** | 높은 데미지, 위험 | 5.2초 |
| **원거리 딜러** | 안전한 거리, 낮은 데미지 | 5.0초 |
| **힐러/서포터** | 회복·버프 | 5.5초 |

---

## 4. ✅ 확정 — 턴제 구조

**파티 턴** (한 명씩 순서대로):
1. 탱커 턴 → 5.7초 윈도우 내 "언제 공격할지?" 심리전.
2. 힐러 턴 → 5.0초 윈도우 (같은 구조).
3. 근접 턴 → 5.2초.
4. 원거리 턴 → 5.5초.

**보스 턴**:
- **단일 공격** → 특정 파티원 타겟. 그 캐릭터만 회피/패링.
- **광역 공격(AoE)** → 파티 전체 **동시에** 회피/패링.

---

## 5. ✅ 확정 — 보스 눈 깜빡임 텔 (심리전 핵심)

- 보스 눈이 3~5번 깜빡이고, **마지막 깜빡일 때 공격 발사체/광역 나옴**.
- 플레이어는 **"몇 번째 깜빡일 때 공격?"** 카운트하면서 타이밍 잡음.
- 패링 성공 = 그 깜빡임 읽고 Perfect ±70ms 잡음(`08` 패막 모듈 재사용).

**간단 예시**:
```
보스 눈:  .   .   .   ●
         (1)  (2)  (3)  (공격)

탱커(5.7초):
  - 3번째 깜빡 후 0.4초에 패링 → Perfect.
```

광역기일 때도 파티 전체가 **같은 깜빡임 카운트**를 보고 협동.

---

## 6. ✅ 확정 — 패링 어드벤티지 (패널티킥 긴장감)

- **실패 = 즉사 아님**. HP 감소 등 손해.
- **성공 = 아주 적절한 어드벤티지**:
  - 데미지 0
  - 카운터 기회(보스 빈틈 노출)
  - 다음 턴 보너스
- → 패링 잘하는 쪽이 게임 유리. 실패해도 복구 가능.

---

## 7. 🟡 설계 — 난이도 변수

- **깜빡임 속도** — 0.3초 간격(어려움) ~ 0.6초(쉬움).
- **깜빡임 횟수** — 3번/4번/5번 랜덤 (예측 방해).
- **광역 빈도** — 보스 턴 3~5회마다 1회 광역.
- **턴 속도** — 한 턴 몇 초? (튜닝 필요).

---

## 8. 🟡 설계 — 화면/UI (개념)

**일반 턴 (단일 공격)**:
```
┌────────────────────┐
│    ◕  (보스 눈)    │  ← 깜빡임 텔 (. . . ●)
│      [보스]        │
│ ●●●●● (HP)        │
├────────────────────┤
│ [탱커] [힐러]      │  ← 파티 (하단)
│ 5.7초   5.0초      │  ← 윈도우
│ [근접] [원거]      │
│ 5.2초   5.5초      │
│  ↓                │  ← 현재 턴 표시
└────────────────────┘
│ [ 공격 ] [ 스킬 ]  │  ← 하단 버튼
```

**광역 턴**:
```
┌────────────────────┐
│    ◕  (보스 눈)    │  ← 전체 화면 번쩍임
│ [ 광역기 예고 ]    │  ← "전원 패막 대기"
├────────────────────┤
│ [탱커] [힐러]      │
│ 5.7초   5.0초      │  ← 각자 윈도우
│ [근접] [원거]      │
│ 5.2초   5.5초      │
└────────────────────┘
```

눈 깜빡일 때 화면 전체 또는 보스 얼굴 주변이 **약하게 번쩍임** (강하지 않게, 텔로서만).

---

## 9. 🟡 설계 — 프로토타입

`demo/modules/party_boss/` — 4인 파티 보스전 한 장면.
- 파티 4인 (탱/근/원/힐) 캐릭터 스프라이트.
- 보스 1종 (눈 깜빡임 애니메이션 + 단일/광역 공격).
- 턴제 흐름 (한 명씩 순서대로).
- 눈 깜빡임 텔 (3~5번, 마지막에 공격).
- 패링(Perfect/Good/Miss) — `parry`·`grid_parry` 모듈 FX/SFX 재사용.
- 광역기 (파티 전체 동시 패막).

**폰 검증 기준**:
- 턴제 흐름 자연스러움.
- 눈 깜빡임 텔 읽기 쾌감.
- 광역기 협동 패링 긴장감.
- 패링 어드벤티지 체감.

---

## 10. 확정 / 보류 / 폐기

### ✅ 확정
- 4인 파티 보스전 구조
- 턴제 (한 명씩 순서대로)
- 광역기 = 파티 전체 동시 회피/패링
- 보스 눈 깜빡임 텔 (심리전 핵심)
- 패링 성공 = 어드벤티지, 실패 = 손해(즉사 아님)
- Walk-to-Play 원칙 유지 (`09`)

### 🟡 보류 (프로토타입/튜닝 위임)
- 파티 역할 구체화 (탱/근/원/힐 조합)
- 턴 속도 (한 턴 몇 초?)
- 광역 빈도 (보스 턴 몇 회마다?)
- 깜빡임 속도/횟수 랜덤 범위
- 난이도 밸런스

### ❌ 폐기 (본 세션)
| 폐기안 | 사유 |
|---|---|
| 1:1 진검승부 구조 (`09`) | 4인 파티 보스전으로 전환 |
| 클레르 옵스퀴르 스타일 (중력 조작·발도체) | 너무 구체 요소에 꽂힘. 패막 + 4인 파티 + 텔만 참고. |
