# 공격 분류 (상/중/하단 + 타입)

> 격투게임(스트리트파이터 3rd 패링 = 상/중/하)에서 영감. **패링 전**에 적의 공격을 **높이(상/중/하) + 타입(발/손/무기)** 로 구분해 읽는 긴장 층. 세부 입력·단 수는 **details-tbd**.

## 두 축 분류

- **높이** — 상단 / 중단 / 하단.
- **타입** — 발 / 손 / 무기(정령무기 포함).

조합으로 공격을 카테고리화. 예: "하단 발공격", "상단 무기공격". 플레이어는 이걸 미리 읽고 대응 패링/회피를 준비.

## 눈 인터페이스와 결합 (★ 핵심)

이사님 "큰 눈 아이콘" 아이디어가 공격 루트를 **보여주는 역할** — 숫자/아이콘 QTE가 아니라 **시선**으로:

- 눈이 **아래** → 하단(발) 예측 / **위** → 상단 / **정면** → 중단.
- 눈이 **발/손/무기** 중 어디를 주시하나 → 타입.

→ "지금 누르세요"가 아니라 **눈 시선으로 루트를 읽는 인터페이스**. 오토배틀러화 차단·show don't tell 원칙 정합.

## 관찰 시스템과 정합

정본 `combat-observation-system.md`의 관찰 단서(발·어깨·무기·눈)가 공격 분류의 근거:

- 적 **발** 움직임 → 하단/발공격 단서.
- **어깨/무기** → 상단/손·무기공격 단서.
- AI 예측이 "우측 공격 68%" → "우측 **상단 무기공격** 68%"로 정밀화.

## 강점

1. **긴장 층 추가** — 단순 타이밍 → "타입/높이 판별 + 타이밍" 다층. 관찰 가치 상승.
2. **격투 깊이** — 상/중/하 가위바위보 + 타이밍.
3. **참모 편향 구체화** — 공격형 참모는 하단 위험 과소평가, 방어형은 상단 과대평가 식(`combat-observation-system` 편향과 연결).
4. **세계별 문법 변주** — 세계마다 상/중/하 의미·규칙이 다름(`faction-by-philosophy` 세계별 전투 문법).
5. **정령무기 연결** — 정령무기 타입이 특정 루트 패링에 유리(하단전 정령무기 등).

## 제약 + 완화 (details-tbd)

- **모바일 한 손** — 상/중/하 3단 패링(방향+타이밍)은 폰에서 무거움 → **2단(상/하)부터**, 확장 시 3단.
- **입력 방식** — 탭 위치 / 스와이프 방향 / 눈 시선 힌트 + 단순 탭. 폰 세로 한 손 최적화.
- **QTE 위험 방지** — 눈 인터페이스가 판단 재료만 제공, 최종 판단은 플레이어.
- **세계별 분류 규칙 매핑**, **정령무기-루트 상성** — 세부 설계 tbd.

## 왜 넣는가

패링 전 긴장을 세우는 층. 관찰·눈 인터페이스·참모 예측·세계별 문법·정령무기를 공격 "루트 읽기"로 묶어 시그니처(패링)의 깊이를 더한다. 기존 정본과 충돌 없이 확장.
